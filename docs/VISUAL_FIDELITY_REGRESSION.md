## 二、自动检查器使用与局限

`scripts/verify_ui_artifact.py` 依赖 Pillow：

```bash
python -m pip install Pillow

# 整图检查：只证明PNG可解码和尺寸正确
python scripts/verify_ui_artifact.py --image final.png --width 1920 --height 1080

# 已认可页面局部编辑：框(x,y,width,height)之外要求逐像素一致
python scripts/verify_ui_artifact.py --image new.png --before approved.png --region 100,200,800,600 --require-change

# 脚本单元测试，使用合成图片，不涉及用户私有设计图
python -m unittest discover -s tests -p "test_verify_ui_artifact.py" -v
```

**默认零容差**，图像不同尺寸或非目标区域出现任何像素/透明度变化一律检查失败。可根据特定渲染来源设置非零容差做诊断，但不得将有容差的结果称为“像素完全不变”。若改动源是HTML/CSS，应辅以真实同环境页面状态截图、DOM/源码差异及人工核查。自动检查不会理解视觉美感、文字是否真实可读、是否模糊、业务是否正确，因此不能单独证明“高清成品通过”。
