## 二、固定 UI 风格库（F01—F12）

### F01｜现代政企商务风
关键词：专业、稳重、规整、高效。清晰顶栏/侧栏、标准化业务组件、合理信息密度、精细表格表单、克制装饰。适用：财政、预算、政务、审批及企业管理后台。

### F02｜现代 SaaS 产品风
关键词：现代、清爽、精细、产品化。产品级排版、统一网格与控件、清晰交互状态、舒适的信息密度。适用：企业系统、综合工作台、应用管理平台。

### F03｜深蓝数字科技风
关键词：数字化、科技感、沉浸、空间层次。深蓝或深色空间背景、数字/光线/粒子等元素、局部高光与适度纵深；科技元素服务于业务主体。适用：登录页、数字门户、科技业务平台。不得自动生成巨大球体、环绕卡片或发光底座。

### F04｜科技 HUD 线框风
关键词：精密、几何、网络、科技仪表。精细线条、几何框架、数据节点、关系网络、低实体感、克制局部光效。适用：系统导航、业务关系展示、科技监控。HUD 不等于处处使用六边形或装饰轨道。

### F05｜现代 2.5D 轻立体风
关键词：空间感、体块、透视、轻量化。等距或适度透视、简洁实体造型、轻量阴影、清晰的前后层次。适用：系统入口、应用导航、业务引导。不得默认使用厚重玻璃、夸张发光或复杂三维舞台。

### F06｜品牌几何创意风
关键词：独特、几何、品牌化、视觉秩序。大面积实色模块、独特几何组织、辨识度高的版式、主次明确。适用：统一门户、应用导航、品牌首页。不能只排列几个几何图标。

### F07｜深色专业控制台风
关键词：专业、深色、精密、高对比。深色中性底、清晰分区、重点操作高对比、紧凑而有序的指标和状态。适用：运营监控、专业工作站、数据管理。

### F08｜现代编辑式设计风
关键词：排版、留白、非对称、品牌感。大胆字体层级、非对称网格、实色模块、清晰节奏。适用：系统门户、应用画廊、品牌工作台。

### F09｜数据可视化驾驶舱风
关键词：指标、数据、图表、监测。核心指标优先、多类型数据图表、明确数据关联和单位范围、合理密度；可深色或浅色。适用：统计大屏、数据驾驶舱、指挥中心。不得以科技装饰代替数据。

### F10｜工业数字监控风
关键词：工程、设备、流程、实时状态。工程网格、设备状态、流程关系、告警和实时监测布局。适用：工业监控、能源、设备运维。

### F11｜清新自然商务风
关键词：温和、舒适、专业、简洁。暖白或中性底、低饱和配色、柔和层次、长时间阅读友好。适用：办公管理、服务平台、日常业务系统。

### F12｜精致微拟物商务风
关键词：材质、质感、细节、真实交互。细腻控件、轻高光、适度按压层次和精细阴影。适用：登录页、操作面板、专业控制组件。不得扩大为厚重玻璃拟态。

**以上是十二种不同的设计方向，不是同一套模板的十二种配色。**

## 三、设计表现层级（L0—L3）

| 代号 | 名称 | 定义 |
| --- | --- | --- |
| L0 | 纯扁平化 | 主要靠颜色、间距和线条分层，无明显实体厚度 |
| L1 | 微立体 | 轻微阴影、局部高光和层次 |
| L2 | 适度 2.5D | 有空间感、透视或体积，但不喧宾夺主 |
| L3 | 明显立体 | 清晰实体造型、光影与纵深；仅按业务和明确要求采用 |

风格和立体程度是独立维度。用户未指定 L 级别时，设计师依据风格及页面任务判断。不能将“科技风”等同 L3，或将“现代感”等同大面积渐变、玻璃与发光装饰。

## 四、固定操作关键词：「选择风格」

**仅当用户明确把「选择风格」作为操作指令时触发。**

1. **展示菜单：** 根据当前设计任务、业务场景与既有约束，展示 F01—F12 的编号、名称、特点；推荐 3—5 种最匹配的风格，说明差异与原因。无具体任务时展示通用目录。不生成图、不修改文件、不擅自确定风格。
2. **接收选择：** 接受单选（`F01`）、多选（`F03、F04、F06`）、风格＋层级（`F01＋L1`）、以及按页面指定（`登录页 F03，导航页 F06，业务页 F01`）。
3. **开始执行：** 选择后沿用已明确的任务、页面数量、业务内容和交付要求；条件齐备时直接设计，不重复要求选择。关键资料缺失时只问最少必要问题。
4. **多风格规则：** 多选默认是**分别制作独立方案**，不擅自融合。用户明确说“融合”时才融合；按指定主辅关系执行，未指定则以先写的风格为主。
5. **重新选择：** 用户说「重新选择风格」时重新展示菜单，保留页面范围与已确认的业务约束，仅重选视觉方向。

操作示例：

- 「选择风格」→ 展示目录与推荐，不开始绘图；
- 「F01」→ 按 F01 设计；
- 「F03、F06」→ 分别制作 F03、F06 独立设计方案；
- 「F01＋F04 融合」→ 以 F01 为主、F04 为辅；
- 「F06，L1，六张页面」→ 六张独立页面，采用 F06/L1；
- 「重新选择风格」→ 返回选择菜单。

## 五、多风格与多页面统一规则

不同方案须在构图、内容组织、导航、组件造型、空间关系、排版层级或色彩体系等方面有**实质区别**；不能只换颜色、背景、阴影或图标。独立页面须单独完整展示，禁止未经要求拼成一张图。

同一套系统需要统一品牌标识、主/辅助色、字体、图标、组件、间距、导航逻辑、按钮及状态；但登录页、系统导航、工作台、数据查询页应各按功能组织，不得为了统一而复制相同构图。**统一设计语言不等于重复页面结构。**

用户明确锁定页面数量、区域、字段、数据、交互、视觉锚点或认可版本时，不得擅自删改。

## 六、明确否定风格的禁止复用

用户本次明确指令及其否定项拥有最高优先级；已被否定的整体视觉套路不得换颜色、名称、位置、图标或局部形态后再次交付。当前门户导航相关的已否定套路包括：

- 大面积浅蓝空背景；
- 巨大中心发光球体；
- 厚重玻璃六边形；
- 少量小卡片围着中心主体漂浮；
- 仅起装饰作用的环形轨道；
- 与操作无关的巨大立体底座；
- 靠渐变与光效撑满页面，实际菜单过小；
- 反复套用已否定的 V2/V3 科技导航模板。

即使选择 F03、F04、F05 等风格，也不自动解除禁止。用户明确指定某种几何业务结构时，可保留其合理信息组织，但不能恢复已否定的整体视觉语言。仅用户明确撤销否定或要求重新采用时才可变更禁用范围。反例不能当正向设计锚点。

## 七、设计质量与交付验收

交付前核对：指定风格是否真正落实；否定模板是否避开；设计构图是否有实质差异；业务场景、信息密度与阅读层级是否合理；整套产品是否统一；页面是否完整；业务字段、按钮、菜单和操作路径是否保留；独立 PNG 数量是否正确；下载文件是否真实存在。

用户指出风格重现或明显偏离，应标记**关键验收失败**并修正，不能包装为“另一种创新”。

交付状态必须区分：**视觉设计、源码、实际运行、测试、提交、合并、部署、ZIP 完整性与用户实际下载**。只有真正执行后才能声称通过；不得将服务端文件存在等同于用户侧可以下载。多图优先聊天内逐张预览，其次独立链接，最后完整 ZIP；链接须指向当前环境已核实的实际文件。
