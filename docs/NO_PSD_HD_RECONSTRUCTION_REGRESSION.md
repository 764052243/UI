# 无PSD高清切图重建｜验收与回归 V1.0

**负责人**：UI000（SKILL、公约、检测器）；**实际重做者**：UI002（大屏）或UI001（系统）。本规范不等于已经重做用户图标/地图/HTML。**仅有1672×941合成图时允许继续高清重建，不得以没Photoshop/PSD停止。**

## 执行优先级

1. 有完整源PSD/PSB、AI/SVG或3D工程 → 从可编辑源真实导出；如有毛边按PS级/等效编辑器精修。
2. 无源层，但图标有明确结构 → **SVG矢量重绘**；精准描摹轮廓、图形重心、线宽、材质、蓝橙光效，使用可编辑路径从源SVG真实输出1x/2x/4x透明PNG。
3. 无源层，但立体底托、地图舞台具有明确透视/层级 → **程序化SVG等距几何或Blender/3D重建**，独立保留体块、底面、倒角、反射、阴影和发光，构成完整视觉单元。
4. 无法矢量表达的复杂纹理 → 原有效像素保真提取/局部像素修复，或AI辅助生成候选并人工修订；**不能靠重复插值声称获得新增真实细节**。原图被遮挡部分为高保真重建，不称无损还原。
5. 任何重建都必须在HTML真实组装并与唯一认可金样逐区比较；**清晰度与还原一致性分别验收**。失败资产不得仅因合成测试通过而交付为合格。

## 验收条目 ND-01～ND-12

| 号 | 场景 | 验收 |
|---|---|---|
| ND-01 | 只有扁平图，无PSD | 不停止；进入无PSD SKILL HD0～HD6 |
| ND-02 | 43×48小导航图标放大四倍 | 判假高清；应有真实SVG路径或可编辑重绘源 |
| ND-03 | SVG套一个base64 PNG | 检查器判FAIL，不能冒充真矢量 |
| ND-04 | SVG只是空标签，没有可见几何 | 判FAIL |
| ND-05 | SVG路径与PNG存在但形状偏离金样 | 人工对照失败，重新描摹，不靠自动合规宣称1:1 |
| ND-06 | 完整底部业务单元被拆成半个底托 | 输出完整复合预览，glyph/plinth对齐，不能只交底托 |
| ND-07 | 程序化底托被改成平面梯形 | 虽可高清渲染，但材质/厚度与金样不符则不通过 |
| ND-08 | 中国地图纹理与连线重建 | 检查几何、光源、区域边界和实际HTML，不得捏造业务数据 |
| ND-09 | 输出PNG像素低于CSS尺寸×DPR | 工具FAIL；须从可编辑源重导 |
| ND-10 | 图片上有黑底矩形与白边 | 棋盘、白底、深底及400%检查，源层/蒙版修复后再验 |
| ND-11 | AI候选未做人工修订 | 只能标候选，不能当用户认可金样的完成品 |
| ND-12 | 无PSD成功输出高清SVG/PNG | 必须再进行实际浏览器同画布截图、原图ROI分区对比、交HTML/ZIP，未实测标未通过 |
