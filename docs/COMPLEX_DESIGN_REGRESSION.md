## 一、核心判分定义

按每例五项判断：**目标定位准确 / 基线与禁止项守住 / 业务或数据完整 / 真正视觉改善 / 证据与交付可信**。每项只判 **通过 / 失败 / 未测**，不为缺少实测的任务填数字。发生关键红线（改错页面、未经许可换色、丢业务字段、无根据编造数据、把重建说成精准编辑、假称源码已运行、图片数量不对）则该例直接失败。视觉审美是否达到预期由用户结合产物逐页判定。

### 判定基线

- 文档/路径检查通过 ≠ 001/002真实会话通过。
- 一例在 Instant 通过 ≠ 所有复杂设计永久通过。
- 没有成对图稿/源码、没有相同素材或没有确定实际档位，就只能报告“本次案例结果”，不能得出精确的跨档位质量变化。
- 12月使用 Instant 时，关键红线 **0 失败**才可把该次具体任务提交用户验收；用户指出失败继续修复，不得静默降级设计要求。
