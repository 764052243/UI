# UI 设计资料库

本仓库是 **UI设计师** 项目的设计资料存储位置，用于保留用户**明确批准归档**的视觉稿、交互原型、页面实现、独立切图与交付记录。

## 正式公约

请先阅读 **[UI设计师｜风格能力库与选择协议 V1.0](UI_DESIGN_CONVENTION.md)**。

公约定义：
- F01—F12 十二类 UI 风格及 L0—L3 立体表现层级。
- 操作关键词 **「选择风格」**：先展示推荐，由用户选择后再设计。
- 多风格默认分别制作、不自动融合；同一套系统统一品牌但不重复构图。
- 对已被用户否定的设计套路永久排除（除非用户明确撤销）。
- 文件检查、图片预览、交付验证和 GitHub 归档权限边界。

## 资料存储原则

**先在会话中设计、预览、验收；获得用户明确同意后，才将指定版本上传至本仓库。** 指定本仓库作为存储地不构成批量上传历史稿件或自动归档后续版本的授权。

推荐的后续归档结构（仅为目录规划，现阶段未建立或上传任何设计稿）：

```text
projects/
  <项目代号>/
    <版本>/
      preview/      # 独立页面 PNG
      source/       # HTML、CSS、JS 等源码
      assets/       # 独立图标与背景切图
      release/      # 经确认的发布包或说明
```

同一版本应标注状态：候选 / 已认可 / 已实现 / 已验证 / 已发布；不能把图片视觉稿当成已经运行的系统。

## 本次初始化范围

本次只创建本 README 和 UI 设计公约，不上传过去六页系统的 V1—V5 设计图、HTML 或 ZIP。未来每次上传需获得对应设计成果的明确授权。
