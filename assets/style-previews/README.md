# 风格参考图归档规范（当前未提供已授权样图）

此目录仅用于**用户明确批准归档**的真实风格参考视觉图；GitHub 中尚未存入相应编号图片时，不得假造链接、以色块或无关照片充数。

## 编号与内容

主风格编号严格遵守共同公约 F01—F12，必须保持定义稳定。大屏的 BS01—BS07 与系统的 SU01—SU08 仅为**场景和构图方式分类**，不替换 F 的含义，也不要求将一张图片自动分别保存三套编号。

- big-screen/：大屏与驾驶舱获授权样图，附场景标签、主 F 编号、L 等级和版权/批准状态。
- system-ui/：登录、门户、导航、工作台、表单等获授权样图，附同类元信息。
- 归档命名建议：F09_BS01_经营驾驶舱_v1.png；F01_SU01_政企业务_v1.png。名称只是示例，**不表示文件已经存在**。

## 菜单与生成边界

用户明确要求「选择风格」时（且属自主创作），F01—F12 每种风格必须展示一张独立原创可识别的视觉示意图，允许先调用图像生成工具现场制作并展示；这与仓库**是否已有归档图**是两个独立事实。仓库没有图时如实说“暂无已归档参考图”，但不能把“暂无”当作完成了必须展示的视觉菜单。如果确实无法生成，明确列为未通过项。

未经用户明确同意，不得把当前设计稿、聊天上传的原图、失败方案、历史 V2/V4/V5 素材或即时生成示意图擅自写入此目录。获批准后需检查解码、尺寸、真实内容、文件路径和对应用途，再提交并回读验证。
